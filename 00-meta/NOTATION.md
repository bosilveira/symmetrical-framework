# Conventions and notation (fixed once)

## The six conventions

| # | Item | Convention |
|---|---|---|
| 1 | Equation | **(M)** is the second-order Master equation; **(E1)** is its first-order level. Always say which. |
| 2 | Regularity | C^2 on the open interval (C^1 is not enough for uniqueness of (E1)). |
| 3 | Domain and reality | Real-valued, defined on all of (0, infinity). Complex-valued solutions and real poles are not considered. |
| 4 | Norm | N(f) = integral of f^2 x dx (the square of the weighted L^2 norm). |
| 5 | Counting | Statements are about nonzero solutions; the family is parametrized by (x0, +-) and the map is one-to-one. |
| 6 | Parameters | r > 0, mu > 0 is the same as s = r^2 > 0, kappa = mu r^2 > 0; other signs are in Theorem 4.2. |

## Symbols

| Symbol | Meaning | Clash avoided |
|---|---|---|
| u | ln x | not ln(x/c) |
| theta | r ln(x/x0), the argument of sech and tanh | not the Gudermannian angle (use gd(theta)) |
| epsilon | y_u^2 - s y^2 + kappa y^4 (first integral of the cubic) | not the Ermakov-Pinney energy (epsilon = 4 E_P there) |
| s, kappa | r^2, mu r^2 | kappa is not mu |
| mu | 4AB (flow invariant, Casimir up to normalization) | |
| W, S | tanh(theta), sech(theta); W^2 + S^2 = 1 | S is not the action |
| J | A e^{ru} + B e^{-ru} (linear backbone), y = 1/J | |
| (E, p) | (J, J'/r) with m = sqrt(mu); or (r J, J') with m = r sqrt(mu). State which. | |
| ' | d/dx on f; d/du on y, phi, a; d/dtheta in Section 5.1 (stated there) | |
| Q_pm, H, H0, D, K | Lewis charges and conformal generators of the EP system | |
| Z_2, Z_3, Z_4 | lattice sums with shift 1/2, shift 0, sign (-1)^n | |

Symbols are written without tildes or diacritics.
