# 3.4 — Riccati closure, linear backbone and initial conditions

The original pair $`(f,W)`$ satisfies, on $`x>0`$,

```math
x f_x=-(1+rW)f,\qquad xW_x=r(1-W^2).
```

Equivalently in $`u=\log(x/c)`$,

```math
S_u=-rSW,\qquad W_u=r(1-W^2).
```

With initial conditions $`W(c)=0`$ and $`f(c)=1/(2c)`$, smooth ODE uniqueness recovers exactly the distinguished kernel. The Riccati equation also has other solution branches (such as constants $`W=\pm1`$) if these initial conditions are omitted.

**Linearization [E].** Set $`J(u)=\cosh(ru)>0`$, $`q=J_u/J=rW`$. Then

```math
J_{uu}=r^2J,\qquad q_u+q^2=r^2.
```

More generally $`J=Ae^{ru}+Be^{-ru}`$ solves the same linear ODE; when $`A,B>0`$,

```math
J^2-\frac{J_u^2}{r^2}=4AB>0.
```

The projective ratio $`q=J_u/J`$ forgets overall amplitude; $`J\mapsto\lambda J`$ leaves $`q`$ unchanged.

**Coupling normalization.** The centered solution of the $`\mu`$-Master has $`y=1/J_\mu`$ with $`J_\mu=\sqrt\mu\cosh(ru)`$. Then $`J_\mu^2-J_{\mu,u}^2/r^2=\mu`$. In particular $`J_\mu`$ should not be silently identified with the unit-normalized $`J=\cosh(ru)`$.

The Riccati flow is an exact projectivization of a rank-two linear system. It does not by itself prove an equivalence with a globally defined geometric connection without selecting domains and boundary data.

## General projective solution and its normalization

The Riccati solution is most transparent as a logarithmic derivative of the linear equation $`J_{uu}=r^2J`$.

**Step 1.** The general real solution of the linear equation is

```math
J(u)=Ae^{ru}+Be^{-ru}.
```

**Step 2.** On any interval where $`J\ne0`$, differentiate and divide:

```math
W(u):=\frac1r\frac{J_u}{J}=\frac{Ae^{ru}-Be^{-ru}}{Ae^{ru}+Be^{-ru}}.
```

**Step 3.** If $`A,B>0`$, the phase lies in $`(-1,1)`$ and may be centered at an arbitrary $`u_0`$:

```math
u_0=\frac{1}{2r}\log(B/A),\qquad W(u)=\tanh(r(u-u_0)),\qquad J(u)=2\sqrt{AB}\cosh(r(u-u_0)).
```

u=\log(x/c)`$.

**Step 4.** If the Master coupling is $`\mu=4AB`$, then $`y=1/J`$ solves the **zero-energy** nonlinear Master:

```math
y(u)=\frac{1}{\sqrt\mu}\mathrm{sech}(r(u-u_0)),\qquad y_u^2-r^2y^2+\mu r^2y^4=0.
```

This proves the exact normalization relation. The ratio $`B/A`$ determines the center; the product $`4AB`$ determines the nonlinear coupling. Neither datum follows from the projective Riccati solution alone.

**Exceptional branches.** If $`A=0`$ or $`B=0`$, $`W=\mp1`$ and $`J`$ is a pure exponential. The reciprocal $`y=1/J`$ then solves the zero-coupling cubic equation, but for fixed $`\mu>0`$ it does **not** solve the cubic Master. If $`AB<0`$, $`J`$ has a real zero and $`1/J`$ has a pole; the globally positive, finite-norm separatrix requires $`A,B>0`$.

## Relation to a two-by-two first-order linear system

For $`X=(J,J_u/r)^{\mathsf T}`$ the scalar equation is equivalent to

```math
X_u=r\begin{pmatrix}0&1\\1&0\end{pmatrix}X,\qquad J^2-(J_u/r)^2=\mu.
```

The quadratic form has signature $`(1,1)`$; the solution flow lies in the connected component of its hyperbola selected by $`J>0`$. Its projective coordinate is $`W=(J_u/r)/J`$. This gives a rigorous conic interpretation **without identifying** the system with a larger exceptional algebra.
