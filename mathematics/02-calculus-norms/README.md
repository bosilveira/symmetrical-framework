# 02 — Calculus, measures and norms

**Norms are foundational**, not merely optional integration examples. The global finite-norm classification uses $`\int_0^\infty xF^2\,dx`$; the unweighted $`L^2(dx)`$ norm has different convergence conditions, and neither should be confused with an $`L^2(dx/x)`$ norm or probability normalization.

Read [differentiation](02-01-differentiation.md), [integration and primitives](02-02-primitives.md), [norms and convergence](02-03-norms.md), then [measure and Hilbert-space transport](02-04-measure-hilbert.md).

The canonical variables are $`x,c,r>0`$, $`u=\log(x/c)`$ and $`S=\mathrm{sech}(ru)`$. The chosen positive kernel is $`f=S/(2x)`$; the coupled profile is $`f_\mu=f/\sqrt\mu`$, $`\mu>0`$. For a general Master solution use the separate symbol $`F`$.
